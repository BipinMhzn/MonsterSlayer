# The Monster Slayer

Simple game developed using Vue js

Use Node.js 22.13 or later. Run `npm ci`, then `npm run serve` for local
development or `npm run build` to generate `dist/`. Run `npm run lint` to
check the source. The app uses Vue 3 and Vite; build assets use relative URLs
so the existing GitHub Pages subdirectory deployment continues to work.

Initally player and monster will have full health 

Player is capable of 
  - attack
  - special attack
  - heal
  - give up
